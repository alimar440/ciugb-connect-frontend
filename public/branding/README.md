# Logos originaux du Club Informatique

Les deux fichiers JPEG originaux fournis par le club sont conservés sans retouche :

- `logo-dark.jpeg` : version sur fond noir (deuxième image).
- `logo-light.jpeg` : version sur fond clair (première image).

Le composant `app-club-logo` utilise la version sombre dans l’en-tête, le pied de page et la carte membre. La variante claire est disponible avec `variant="light"`.

Le symbole est cadré en CSS pour garder l’en-tête et la carte lisibles à petite taille ; les fichiers complets restent disponibles dans ce dossier. Aucun logo n’a été redessiné ou généré.
